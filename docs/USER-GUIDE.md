# 使用说明 · 0.5.0

## 启动与文件定位

解压完整下载包，运行“中国机场跑道标线工具.exe”。第一次启动会查找 X-Plane 安装记录、Steam 库和常见位置；找不到时进行有限深度的本地磁盘搜索。成功后直接填入 `apt.dat` 完整路径并加载机场。找到多个安装时选择要处理的具体文件。

非常规位置或外置盘可通过“浏览文件…”选择。路径会自动记住，下次无需再找。文件未变化时使用机场缓存；更新后自动重新扫描。手动编辑输入框后请点击“扫描中国机场”。

默认导出位置是“文档/中国机场跑道标线工具导出”。可选择其他独立目录，不能把导出目录放在当前 Global Airports 所在的 X-Plane 安装目录中。

## 勾选与应用

1. 完全退出 X-Plane。
2. 逐机场勾选，或点击“勾选推荐项”。推荐项跳过透明跑道机场；每次新扫描 / 启动不会自动勾选。
3. 点击“生成完整修正版 apt.dat”。导出包含完整 `apt.dat`、SHA-256 清单和手动替换说明。
4. 弹窗会显示修改数量、目标原文件和导出位置。
5. 选择“是”：校验源文件与导出，生成原版备份，再替换该源文件。选择“否”：保留导出，原文件不变。
6. 下次启动 X-Plane 时读取新数据。生效目标是弹窗显示的文件；独立 apt.dat 副本不会自动覆盖到其他 X-Plane 安装。

不改变地景加载顺序；第三方机场如果覆盖默认机场，其自定义跑道贴图可能不会受 Global Airports 修改影响。

## 一键恢复

选中先前应用过的 `apt.dat`，点击“一键恢复原版备份”，确认后恢复到这一轮连续修改之前的原始内容。多次应用不会把已修改内容覆盖成原版。

备份位置：`apt.dat` 同目录下的 `.ChinaRunwayMarkingsBackups`。

每次应用会建立独立目录，保存修改前的 `before.dat`、替换回退文件 `rollback.dat` 和 `record.json`。记录中的 `OriginalFile` 指向这一轮修改最初的原版；请保留整个备份目录，勿单独改名、删除或移动其中的文件。恢复后的备份也会保留。

工具会核对当前文件和原版备份的哈希。如果数据库被更新或其他工具修改，会停止自动恢复，避免覆盖新的机场数据。无需重复恢复时会提示当前文件已是原版。

## 常见情况

- **没有找到文件**：点击“浏览文件…”选择 X-Plane 内 Global Airports 的 `apt.dat`，以后自动记住。查找只在有限深度内进行，不保证找到所有非常规安装。
- **找不到可转换机场**：当前数据可能已经采用 ICAO / EASA 标线。仅 2 / 3 编码会转换，其他编码不变。
- **拒绝应用，源文件发生变化**：重新扫描更新后的文件，重新勾选和生成。
- **X-Plane 正在运行**：完全退出模拟器后重试。工具不会替你结束游戏进程。
- **无写入权限、磁盘不足、文件被占用**：解决对应原因后重试。备份和临时文件需要额外空间；操作失败时现存备份仍保留。
- **无法保存路径**：检查本机 `%LOCALAPPDATA%/ChinaRunwayMarkings` 目录是否可写。缓存不可用时仍可重新扫描。
- **游戏更新之后**：重新扫描、生成并应用到新版本数据库，形成新的原版备份。不要手动用旧导出覆盖新数据库。
- **手动回退**：在退出 X-Plane 后，根据相应 `record.json` 中的 `OriginalFile` 找到原版副本，核验对应 `OriginalSha256` 后再决定是否手动恢复。
